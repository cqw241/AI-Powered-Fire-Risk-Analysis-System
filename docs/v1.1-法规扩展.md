# v1.1 法规扩展：GB 55036-2022

## 范围

v1.1 在 v1 基础规则包之上增加《消防设施通用规范》GB 55036-2022 的视觉可判定规则。

本版本坚持以下边界：

- `clause_text` 只保存已核对的法规/标准原文，不保存摘要或 AI 改写；
- 解释、视觉证据边界和不能由单图确认的信息只写入 `engineering_note` 或 `missing_conditions`；
- Qwen 只输出视觉 Finding 和受控 Issue Code，不直接输出法规条款或违法结论；
- 仅纳入本轮已经逐条核对的 4 个来源条款；
- GB 55036-2022 4.0.5 不整体绑定视觉问题，而精确拆分到第二项。

## 本版本条款

### GB55036-2.0.9

> 消防设施投入使用后，应定期进行巡查、检查和维护，并应保证其处于正常运行或工作状态，不应擅自关停、拆改或移动。超过有效期的灭火介质、消防设施或经检验不符合继续使用要求的管道、组件和压力容器不应使用。

视觉边界：图片可以提供消防设施明显损坏、拆改、移动或停用标识等线索；是否定期维护、是否擅自关停、是否超过有效期以及实际功能状态通常需要管理记录或现场测试。

### GB55036-2.0.10

> 消防设施上或附近应设置区别于环境的明显标识，说明文字应准确、清楚且易于识别，颜色、符号或标志应规范。手动操作按钮等装置处应采取防止误操作或被损坏的防护措施。

视觉边界：可以识别已经出现的消防设施标识被遮挡、覆盖、明显破损或难以识别；单张图片中没有拍到标识不能推断现场不存在标识。

### GB55036-4.0.5-2

对应 GB 55036-2022 第 4.0.5 条第二项：

> 喷头周围不应有遮挡或影响洒水效果的障碍物；

该子项单独建 `clause_id`，避免把需要水力计算、建筑高度、系统类型等外部事实的 4.0.5 其他项目错误绑定到单图视觉判断。

### GB55036-10.0.4

> 灭火器应设置在位置明显和便于取用的地点，且不应影响人员安全疏散。当确需设置在有视线障碍的设置点时，应设置指示灭火器位置的醒目标志。

视觉边界：对已识别灭火器，可以判断明显遮挡、压住或妨碍取用；是否影响安全疏散、是否属于需要额外位置指示的视线障碍场景，应结合完整现场条件判断。

## 新增 Issue Code

### `SPRINKLER_OBSTRUCTED`

已明确识别的自动喷水灭火系统洒水喷头周围存在货物、装修构件、管线或其他物体明显遮挡，可能影响洒水效果。

确定性映射：

- `GB55036-4.0.5-2` → `direct`

### `FIRE_FACILITY_MARKING_OBSCURED_OR_DEFECTIVE`

已明确识别的消防设施上或附近的标识存在被物体遮挡、覆盖、明显破损或内容难以识别的可见状态；单张图片未拍到标识不视为标识缺失。

确定性映射：

- `GB55036-2.0.10` → `direct`

## 复用现有 Issue Code

### `EXTINGUISHER_OBSTRUCTED`

新增优先映射：

- `GB55036-10.0.4` → `direct`

已有其他法律/管理规定映射仍保留，由规则排序和每个 Finding 最多 3 条法规的现有机制处理。

### `FIRE_FACILITY_DAMAGED_OR_DISABLED`

新增映射：

- `GB55036-2.0.9` → `conditional`

原因：图片能看到损坏、停用或拆改线索，但“实际工作状态”“是否擅自”“维护情况”等不能仅靠单图确认。

## 数据文件

Risk Pack Loader 重构后，v1 与本版本数据已原样合并到生产规则包：

- `data/legal/risk_packs/cn-mainland-fire-safety/manifest.json`
- `data/legal/risk_packs/cn-mainland-fire-safety/clauses.json`
- `data/legal/risk_packs/cn-mainland-fire-safety/issue_codes.json`
- `data/legal/risk_packs/cn-mainland-fire-safety/rule_bindings.json`

实际运行路径 `get_rule_catalog()` 通过 manifest 自动发现并加载所有启用的纯数据规则包。
`load_rule_catalog(issue, binding, clause)` 继续作为旧三文件调用的兼容入口，但与新 Loader 复用同一套
模型和 RuleCatalog 校验逻辑。Qwen Prompt 直接使用 Loader 生成的统一 RuleCatalog。

## 验收点

- v1 与 v1.1 规则数据内容保持不变，并由 manifest 驱动加载；
- v1.1 运行时 Catalog ID 为 `cn-mainland-v1.1`；
- 4 个 GB 55036 条款能通过规则目录结构校验；
- 两个新增 Issue Code 能进入 Qwen Prompt；
- 喷头遮挡能直接映射到 `GB55036-4.0.5-2`；
- 消防设施标识明显遮挡/破损能直接映射到 `GB55036-2.0.10`；
- 灭火器遮挡优先出现 `GB55036-10.0.4`；
- 消防设施损坏/停用对 `GB55036-2.0.9` 保持条件性关联。
